StudyBuddy Website

StudyBuddy is a tutoring website created to help university students find academic support in subjects such as Mathematics, Accounting and Programming.

Website Features

* Home page
* About page
* Subjects page
* Tutors page
* Booking page
* Contact page
* Responsive navigation
* Booking and contact forms

Technologies Used

* HTML
* CSS
* JavaScript
* GitHub
* GitHub Pages

Live Website

https://oratilemoha.github.io/StudyBuddyWebsite/

Project Purpose

The purpose of this website is to provide students with an easy way to find tutoring information, view available subjects and tutors, and request tutoring sessions online.
